# Hive Shield — WhatsApp Deepfake Detector (Hackathon Problem DVPS14)

### Browser Extension for Detecting Deepfakes & Manipulated Images in WhatsApp Web

This extension directly fulfills the requirements of **Problem Statement DVPS14**:
*"A browser extension/app that detects deepfake videos and manipulated images shared in family WhatsApp groups."*

---

## 🚀 How to Install & Test the Browser Extension (For Judges)

You can load this extension in Google Chrome, Microsoft Edge, or Brave in under 30 seconds:

1. Open your browser and navigate to:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
2. Toggle on **"Developer mode"** in the top-right corner.
3. Click **"Load unpacked"** in the top-left corner.
4. Select this `extension/` folder:
   `.../gentle-content-guard/extension`
5. Open [WhatsApp Web](https://web.whatsapp.com) in your browser:
   - As videos or forwarded images appear in family chats, the Hive Shield badge automatically overlays on suspicious media.
   - Click the badge to view the deepfake risk score, ELI5 explanation for elders, and a 1-click button to copy a polite rebuttal message back into the chat!

---

## 🌟 Key Features
1. **WhatsApp Web Native Interceptor**: Monitors incoming media forwards automatically.
2. **Video Face-Swap & Lip-Sync Detection**: Detects desynchronized mouth movements, missing blinks, and warping seams.
3. **1-Click WhatsApp Rebuttal Card**: Generates respectful debunking text ready to paste directly into family groups to halt misinformation without causing family friction.
4. **Full Web Companion App**: Live at [gentle-content-guard.lovable.app](https://gentle-content-guard.lovable.app).
